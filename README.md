# UGME Student Evaluation Portal — VS Code Starter

## Open the website
1. Install Visual Studio Code from https://code.visualstudio.com/.
2. Extract the ZIP archive.
3. In VS Code, choose **File → Open Folder** and select `UGME_Website_VSCode`.
4. Open `index.html` in your browser. Optionally use the VS Code Live Server extension for live previews.
5. Edit `style.css` for colors/layout, `index.html` for navigation, and `app.js` for behavior.

## Demo workflow
- In **Faculty Directory**, add sample faculty.
- In **Department Admin**, assign an evaluation to a sample student.
- In **Student Portal**, submit a sample faculty evaluation.
- In **Reports**, export the demo data as CSV.
- In **Form Builder**, add or remove sample questions.

## Important limitations
- This is a local **prototype**, not a deployed or secure application.
- Data is saved only in your browser's `localStorage` on that device and may be lost if cleared. It is NOT saved to SharePoint or Moodle.
- Role navigation is a demo and does NOT enforce access permissions.
- Do NOT enter real student names, IDs, evaluation responses or other confidential information.
- Actual AKU student authentication, secure backend, SharePoint integration, anonymous/confidential response handling, audit logs and backups require IT approval and further development.
- The remaining evaluation questionnaires and year-specific differences are not implemented because their questions have not been provided.
